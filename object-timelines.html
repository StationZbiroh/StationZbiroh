How to use the archive

Start with the object you are interested in. Follow a dated event to its evidence page when you need detail. Use the connected timeline when you want to see what was happening elsewhere in the landscape at the same time. Use the source catalogue when you need provenance, and the research register when you want to see what remains unresolved.
