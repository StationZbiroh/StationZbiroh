# Emil Brandeis image collection

Dedicated image directory for the Stanice Zbiroh Historical Research Archive page **Who was Emil Brandeis?**

## Upload target

Place original photographs and scans connected with Emil Brandeis and the Brandeis family in this directory. Preserve original files wherever possible. Digitally enhanced or reconstructed images should be clearly identified as viewing copies.

The historical Borek factory postcard already preserved elsewhere in the repository may be used as the initial header image for the Emil Brandeis biography page.
