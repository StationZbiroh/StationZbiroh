# Brandeis–Eisenschimmel factory images

This folder preserves historical images associated with the Borek factory and the company trail of the Brandeis and Eisenschimmel families.

## Archival handling

- Original scans and photographs are primary-source reproductions and should remain unaltered.
- Digitally enhanced versions must be identified as viewing copies.
- Enhancement must not be presented as newly discovered historical detail.
- Record provenance, approximate date, physical inscriptions, and any uncertainty wherever known.
